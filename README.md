# ForgeChat 🚀

A production-grade AI assistant built from the ground up using LangGraph and modern AI Engineering practices.

ForgeChat starts as a simple conversational chatbot and gradually evolves into a production-ready AI system with persistent conversations, RAG, tool calling, memory, agents, human-in-the-loop workflows, evaluation, observability, and more.

---

## 🎯 Project Goal

The goal of ForgeChat is not just to build another chatbot.

It is a hands-on AI Engineering project designed to explore how production-grade AI applications are designed, built, evaluated, debugged, and deployed.

---

## 🏗️ Evolution

ForgeChat will be developed incrementally:

- [ ] Basic LangGraph Chatbot
- [ ] Stateful Conversations
- [ ] Persistent Conversations
- [ ] RAG
- [ ] Advanced RAG
- [ ] Tool Calling
- [ ] Agentic Workflows
- [ ] Memory
- [ ] Human-in-the-Loop
